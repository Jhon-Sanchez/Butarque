# Mapa vivo de Butarque

## Descripción del proyecto

Este proyecto consiste en desarrollar una aplicación para Android sobre el barrio de Butarque. La idea es mostrar información sobre diferentes lugares y aspectos importantes del barrio, para que cualquier persona pueda conocer un poco mejor su historia y cómo ha ido evolucionando.

La aplicación está organizada en varios apartados, cada uno dedicado a un tema diferente.

## Objetivo

El objetivo principal es crear una aplicación sencilla y fácil de utilizar, donde se pueda consultar información sobre Butarque desde el móvil.

Queremos reunir en una misma aplicación distintos puntos de interés del barrio y mostrar su información de una forma organizada.

## Apartados de la aplicación

La pantalla principal cuenta con cuatro apartados:

- **Yacimientos:** recoge información sobre los restos arqueológicos y lugares históricos.
- **Industria:** muestra información relacionada con la actividad industrial del barrio.
- **Vida vecinal:** trata sobre la historia de los vecinos y la evolución de la vida en el barrio.
- **Equipamientos:** incluye información sobre diferentes instalaciones y servicios de Butarque.

## Tecnologías utilizadas

Para desarrollar la aplicación estamos utilizando:

- Kotlin, como lenguaje de programación.
- Android Studio, como entorno de desarrollo.
- Jetpack Compose, para crear las pantallas y los elementos de la aplicación.
- Material 3, para los componentes visuales.
- Gradle, para gestionar el proyecto y sus dependencias.

## Cómo abrir el proyecto

Para ejecutar la aplicación hay que seguir estos pasos:

1. Descargar el repositorio desde GitHub.
2. Abrir Android Studio.
3. Seleccionar la carpeta del proyecto.
4. Esperar a que termine la sincronización de Gradle.
5. Iniciar un emulador o conectar un dispositivo Android.
6. Pulsar en Run para ejecutar la aplicación.
